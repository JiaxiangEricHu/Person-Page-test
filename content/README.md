# 编辑入口

- site.json：个人资料、三组名称、标签与联系按钮。
- ui.json：网站界面文字。
- design.json：颜色、字体、布局和面板显示。
- scene.json：三维材质、尺寸比例、动画与性能。
- projects/*.md：每篇项目的标题、封面、正文与发布状态。
- project-template.md：新增项目时复制此模板。

archives.json 自动生成。config-fields.json 和 schemas 是字段定义，日常无需修改。所有参数的说明见根目录 CONFIG_REFERENCE_ZH.md；维护流程见 EDITING_GUIDE_ZH.md。
